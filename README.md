# 国歌クイズ

国歌の演奏を聴いて、どの国の国歌かを4択で当てるクイズです。
ブラウザだけで遊べます。インストールもアカウント登録も不要で、無料です。

**▶ 遊ぶ：https://national-anthem-quiz.tkhm110.workers.dev**

## 遊び方

1. 地域と難易度を選んで「スタート」を押します。
2. 「再生」を押して、国歌の演奏を聴きます（冒頭から最大60秒。歌のない器楽演奏です）。
3. 4つの国名から答えを選びます。正解・不正解と、正解の国名・曲名が表示されます。
4. 1プレイは最大10問です。最後に結果が表示されます。

スマートフォンでも遊べます。ダークモードとキーボード操作にも対応しています。

## モード

地域と難易度の組み合わせで、出題される国が決まります。

| 選べるもの | 内容                                                                           |
| ---------- | ------------------------------------------------------------------------------ |
| 地域       | 全世界 / アジア / ヨーロッパ / アフリカ / 北アメリカ / 南アメリカ / オセアニア |
| 難易度     | 初級 / 中級 / 上級 / 超級（難易度を上げるほど、出題される国が増えます）        |

- 正解も、ほかの3つの選択肢も、選んだ地域・難易度の国だけから出題されます。
- 収録している国がまだ少ない組み合わせは、選択画面に「—」と表示され、遊べません。
  収録国が増えると、遊べる組み合わせも増えます。

## 音源について

- 音源は、[Wikimedia Commons](https://commons.wikimedia.org/) で公開されているものを使っています。
  中国を除くすべてが、**米海軍軍楽隊（United States Navy Band）の演奏**です。
- 米海軍軍楽隊の音源は、1曲ずつ、**楽曲と演奏の両方がパブリックドメインである**ことを確認したものだけを収録しています。
  確認しきれなかった国歌は、収録を見送っています。
- 中国の国歌だけは、Commons の利用者 Zscout370 さんが作った演奏で、[CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/) で公開されているものです（形式を MP3 に変換しています）。
- 各音源の出典は、クイズの画面の下にある「音源の出典とライセンス」で見られます。
- 権利について気づいた点があれば、[Issues](https://github.com/tkhm110/national-anthem-quiz/issues) でお知らせください。

## 出題のこだわり

- **聴き分けられない国歌は、同じ4択に並べません。**
  同じ旋律を使う国歌（たとえばイギリスとリヒテンシュタイン）があるため、音だけでは正解が決まらない問題を作らないようにしています。
- 選んだ地域・難易度の国が足りないときも、ほかの地域の国で数合わせをしません。
- 出題の仕組みは、画面から切り離した小さなプログラムとして作り、自動テストで確かめています。

## 使っている技術

| 用途           | 技術                                   |
| -------------- | -------------------------------------- |
| 画面           | React + TypeScript（Vite でビルド）    |
| データの検証   | Zod（国データ）、音源ファイルの検査    |
| テスト         | Vitest                                 |
| 自動チェック   | GitHub Actions（PR ごとに検証）        |
| 公開           | Cloudflare Workers（静的サイトの配信） |
| 依存関係の更新 | Dependabot                             |

サーバー側のプログラムはなく、静的なファイルだけで動きます。

## 手元で動かす

Node.js 24 と pnpm 10 が必要です。

```bash
pnpm install
pnpm dev      # 開発サーバーを起動
pnpm test     # テストを実行
pnpm build    # 公開用にビルド
```

仕様（出題ルール、データの形式、国の追加手順）と、開発・運用の詳細は、[docs/development.md](docs/development.md) にまとめています。

## このプロジェクトについて

個人の学習を兼ねたプロジェクトです。AI のコーディングエージェントと役割を分けて開発しています。

- 実装：Claude Code
- レビュー：Antigravity CLI（Gemini）と Codex
- マージの条件：GitHub Actions の自動チェック

エージェントに守らせているルールは [AGENTS.md](AGENTS.md) に、レビューの基準は [REVIEW.md](REVIEW.md) にあります。

不具合の報告や、収録してほしい国の提案は、[Issues](https://github.com/tkhm110/national-anthem-quiz/issues) へお願いします。
